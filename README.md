# gambaryan

Репозиторий содержит реализацию трёх библиотек на языке C, разработанных в рамках учебного курса.  
Все функции написаны с нуля без использования стандартных библиотек (за исключением строго оговорённых случаев) и покрыты модульными тестами.

---

## Содержание

1. [String+](#string) – расширенная работа со строками (Индивидуальный)  
2. [Math](#math) – собственная реализация математических функций (Индивидуальный)
3. [Decimal](#decimal) – арифметика с десятичными числами фиксированной точности (Групповой)

## 1. String+ <a name="string"></a>

### Постановка задачи
Разработать собственную библиотеку для работы со строками, аналогичную `<string.h>`, а также реализовать функцию `sprintf` с поддержкой большого набора спецификаторов и флагов форматирования.

### Реализованные функции
- `memchr`, `memcmp`, `memcpy`, `memmove`, `memset` – работа с блоками памяти.
- `strcat`, `strncat` – конкатенация строк.
- `strchr`, `strrchr` – поиск символа.
- `strcmp`, `strncmp` – сравнение строк.
- `strcpy`, `strncpy` – копирование.
- `strcspn`, `strspn` – длина сегмента без/с набором символов.
- `strerror` – получение сообщения об ошибке по номеру (поддерживаются Linux и macOS).
- `strpbrk` – поиск первого совпадения из набора символов.
- `strstr` – поиск подстроки.
- `strtok` – разбиение на лексемы.
- `sprintf` – форматированный вывод в строку (поддержка `%c, %d, %i, %f, %s, %u, %x, %X, %o, %p, %n`; флаги `-, +, (space), #, 0`, ширина, точность, модификаторы `h, l, L`).

### Ключевые подходы
- Все строковые операции реализованы через указатели и арифметику адресов, без использования стандартных функций.
- Для `sprintf` разработан конечный автомат парсинга формата, который обрабатывает флаги, ширину, точность и модификаторы, а затем вызывает внутренние утилиты преобразования чисел и строк.
- Поддержка разных платформ (Linux/macOS) для `strerror` реализована через условную компиляцию.
- Тесты покрывают как базовые функции, так и сложные случаи `sprintf` (комбинации флагов, звёздочка для ширины/точности).

## 2. Math <a name="math"></a>

### Постановка задачи
Реализовать набор математических функций, аналогичных `<math.h>`, с корректной обработкой особых случаев (бесконечность, NaN, нуль).

### Реализованные функции
- `abs` – модуль целого числа.
- `fabs` – модуль числа с плавающей точкой.
- `fmod` – остаток от деления.
- `pow` – возведение в степень (включая дробные и отрицательные показатели).
- `exp` – экспонента.
- `log` – натуральный логарифм.
- `sin`, `cos`, `tan` – тригонометрические функции.
- `asin`, `acos`, `atan` – обратные тригонометрические функции.
- `sqrt` – квадратный корень.
- `floor`, `ceil` – округление вниз/вверх.

### Ключевые подходы
- Тригонометрические и логарифмические функции реализованы через разложение в ряды Тейлора/Маклорена с заданной точностью.
- Для `pow` используется тождество `x^y = exp(y * ln(x))` с проверкой краевых случаев (отрицательное основание, нуль, бесконечность).
- Функции `floor` и `ceil` работают через явное преобразование к целому типу с учётом знака.
- Обработка `NaN` и `INF` выполняется с помощью макросов `S21_ISNAN` / `S21_ISINF` (через сравнение с самим собой и с бесконечностью).
- Все тесты сравнивают результаты с эталонной библиотекой `math.h` с допустимой погрешностью.

## 3. Decimal <a name="decimal"></a>

### Постановка задачи
Реализовать тип `s21_decimal` для хранения десятичных чисел с фиксированной точностью (7 слов по 32 бита: 3 слова мантиссы, 1 слово для знака и степени, 3 дополнительных слова для промежуточных вычислений). Библиотека должна поддерживать арифметические операции, сравнения, преобразования и округления в соответствии со спецификацией.

### Реализованные функции
**Арифметика:**
- `s21_add`, `s21_sub`, `s21_mul`, `s21_div`, `s21_mod` – сложение, вычитание, умножение, деление, остаток.

**Сравнение:**
- `s21_is_less`, `s21_is_less_or_equal`, `s21_is_greater`, `s21_is_greater_or_equal`, `s21_is_equal`, `s21_is_not_equal`.

**Преобразования:**
- `s21_from_int_to_decimal`, `s21_from_decimal_to_int`, `s21_from_float_to_decimal`, `s21_from_decimal_to_float`.

**Прочие:**
- `s21_floor`, `s21_round`, `s21_truncate`, `s21_negate`.

### Ключевые подходы
- Для выполнения операций используется расширенный тип `s21_decimal_x2` (7 слов), в котором хранятся промежуточные результаты с запасом по разрядности.
- Масштабирование (нормализация) выполняется путём умножения на 10 с переносом между 32-разрядными словами, что позволяет сохранять точность.
- Деление реализовано через битовый сдвиг и вычитание, с последующим подбором точности (до 28 знаков после запятой).
- Функция `otkat` выполняет банковское округление и корректировку степени после каждой операции.
- Для сравнения числа приводятся к общему масштабу, затем сравниваются побитово с учётом знака.
- Преобразование из `float` в `decimal` использует извлечение экспоненты и мантиссы из представления IEEE 754, а затем масштабирование до целого числа.
- Тесты покрывают сотни сценариев, включая пограничные случаи (переполнение, деление на ноль, очень маленькие числа) и сравниваются с ожидаемыми значениями.

## Сборка и тестирование

Все проекты собираются с помощью `Makefile` (каждый в своей директории). Для запуска тестов используется библиотека **Check**.

Пример для сборки и запуска тестов:
```bash
cd String/src && make test
cd ../../Math/src && make test
cd ../../Decimal/src && make test
```

Тесты выполнены в стиле check и покрывают все функции библиотек.

## Особенности реализации
Весь код написан на C11 с использованием только разрешённых библиотек (stdio.h, stdlib.h, math.h для проверки в тестах, check.h для тестов).
В проекте Decimal используется собственная битовая арифметика для упаковки чисел.
В проекте String реализован полноценный парсер формата sprintf, поддерживающий большинство спецификаторов из стандарта.
В проекте Math все функции возвращают результаты, согласующиеся с эталонной библиотекой в пределах допустимой погрешности.
